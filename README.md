This Looper supports overdubbing and multi-layering audio. It has an undo layer and save buttons. When saving, it saves each layer as its own .wav file.
Saves should be located in loops/saved.
To start/stop recording, use the spacebar. 
Currently, the length of the loop is determined by the longest track, and playback stops while recording.

In the future, I'll try to add the option of choosing whether playback plays while recording and to visually show the length of previous tracks.
Also will try to add a metronome.
